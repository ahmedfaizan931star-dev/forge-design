# FORGE® — Independent Design Studio Landing Page

A production-ready, responsive landing page template built with a single-file architecture (`index.html`). It combines semantic markup, modern CSS custom properties, and zero-dependency vanilla JavaScript to deliver agency-grade performance and aesthetic quality.

![FORGE Studio Preview](https://raw.githubusercontent.com/YOUR_USERNAME/forge-design-studio/main/preview.png)

## ✨ Key Features

- 🎨 **Editorial Design System:** Expressive typography pairing featuring *Fraunces*, *Inter*, and *JetBrains Mono*[span_0](start_span)[span_0](end_span).
- 🌓 **Dynamic Light/Dark Mode:** Full theme toggling with instant switching and persistent state via `localStorage`[span_1](start_span)[span_1](end_span).
- ⚡ **Zero-Dependency Animations:** Built-in `IntersectionObserver` scroll-reveal engine, marquee ticker, count-up statistics, and scroll progress tracking[span_2](start_span)[span_2](end_span).
- 📱 **Fluid & Responsive:** Built with CSS Grid and flexbox layouts that scale down to mobile[span_3](start_span)[span_3](end_span).
- 🚀 **Single-File Architecture:** Zero setup, zero npm packages, and no build pipeline required[span_4](start_span)[span_4](end_span).
